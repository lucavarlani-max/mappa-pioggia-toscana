# Mappa Pluviometrica Toscana

Mappa interattiva delle precipitazioni cumulate in tutta la Toscana, con i dati reali
dei pluviometri del Servizio Idrologico Regionale (SIR).

**Sito online:** https://lucavarlani-max.github.io/mappa-pioggia-toscana/

I dati si aggiornano automaticamente ogni giorno tramite GitHub Actions
(vedi .github/workflows/aggiorna.yml). Fonte: http://www.sir.toscana.it/ (CC-BY-SA).
Mappa: OpenStreetMap. Radar meteo: RainViewer.

Per pubblicazione e manutenzione vedi GUIDA_PUBBLICAZIONE.md e LEGGIMI.md.
